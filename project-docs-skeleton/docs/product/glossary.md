# Glossary – thuật ngữ nghiệp vụ

> Tầng 1 – Sản phẩm. Spec, plan, code và API phải dùng đúng các thuật ngữ này. Thuật ngữ mới phát sinh trong một tính năng phải được thêm vào đây trước khi dùng.

| Thuật ngữ | Tên trong code | Định nghĩa | Không dùng (từ đồng nghĩa gây nhầm) |
| --- | --- | --- | --- |
| {Đơn hàng} | `Order` | {Yêu cầu mua hàng đã được khách xác nhận} | {Phiếu, booking} |
| {Giỏ hàng} | `Cart` | {Danh sách sản phẩm khách chọn, chưa xác nhận} | {Basket} |
| {Khách hàng} | `Customer` | {…} | {User (chỉ dùng cho tài khoản đăng nhập)} |
